Problem Statement

Given an array of N integers, reverse the array in-place without using any auxiliary data structure. You must achieve this in O(N) time complexity and O(1) space complexity.


The reversal must be performed on the original array. Return the modified array as a single space-separated line of integers. Partial solutions will not be awarded points — the entire sequence must match the expected output exactly.

Input Format

Line 1: A single integer N — the number of elements.
Line 2: N space-separated integers representing the array elements.

Constraints
  • 1 ≤ N ≤ 106
  • -109 ≤ A[i] ≤ 109
  • Time limit: 1.0s
  • Memory limit: 256 MB
  • No auxiliary array or deque allowed
Output Format

Print the reversed array on a single line, elements separated by a single space. No trailing whitespace. No leading whitespace.

Sample Cases
// SAMPLE_01
Input
5
1 2 3 4 5
Output
5 4 3 2 1
Explanation

Array [1, 2, 3, 4, 5] reversed in-place yields [5, 4, 3, 2, 1]. Swap index 0↔4, then 1↔3. Index 2 (the middle) stays fixed.

// SAMPLE_02
Input
6
-3 0 7 -1 4 2
Output
2 4 -1 7 0 -3
Explanation

Six-element array with mixed positive and negative values. Note that -3 moves to the last position and 2 to the first. No auxiliary structure is used — only in-place two-pointer swaps.
